# Frontend

React + TypeScript веб-приложение для отслеживания арбитражных возможностей на криптовалютных биржах.

- SPA на React 19 с TanStack Router для роутинга и TanStack Query для кэширования.
- MUI 9 UI-компоненты + Lightweight Charts для графиков.
- Генерация API-клиента из OpenAPI схемы бэкенда.

## Стек технологий

- **React 19** — UI-фреймворк
- **TypeScript 5.9** — строгая типизация
- **Vite 8** — сборщик и dev-сервер
- **TanStack Router** — роутинг с автогенерацией routes
- **TanStack Query** — кэширование и управление серверным состоянием
- **MUI 9** — UI-компоненты (Material UI)
- **Lightweight Charts** — графики цен
- **openapi-fetch** — HTTP-клиент, сгенерированный из OpenAPI


## Возможности

- **Отслеживание арбитража** — таблица арбитражных возможностей в реальном времени
- **Демо-режим** — предпросмотр таблицы без подключения к API
- **История сделок** — таймсерии open/close позиций
- **Авторизация** — регистрация, вход, управление профилем
- **Генерация API-клиента** — автоматическая генерация из OpenAPI схемы бэкенда
- **Тёмная/светлая тема** — кастомизируемая тема MUI
- **Алиасы импортов** — удобная навигация по проекту (`@pages`, `@shared`, `@widgets`)
- **Production-сборка** — оптимизированная сборка через Vite

│   └── user/          # Функциональность пользователя
├── shared/            # Общие модули
│   ├── api/           # API-клиенты и типы (из OpenAPI)

## Быстрый старт

### 1. Установка

Копировать репозиторий
```bash
git clone https://github.com/iadzhak-arb/frontend.git
cd frontend
```

Настроить окружение
```bash
# Установите зависимости
npm install
```

### 2. Запуск

> Перед запуском необходим запущенный бэкенд для генерации API-клиента.

Dev-сервер
```bash
npm run dev
```

Генерация API-клиента
```bash
npm run arb
```

Production-сборка
```bash
npm run build
```

## API и генерация типов

Проект использует **OpenAPI** для генерации TypeScript-типов и HTTP-клиента.

Генерация API-клиента
```bash
npm run arb
```

Эта команда скачивает схему OpenAPI с бэкенда (`http://127.0.0.1:8000/api/schema/`) и генерирует типизированный клиент в `src/shared/api/schema.ts`.

> **Важно:** Бэкенд должен быть запущен для генерации API-клиента.
