## 🛠 Технологии

| Технология             | Назначение                                    |
|------------------------|-----------------------------------------------|
| **React 19**           | UI-фреймворк                                  |
| **TypeScript 5.9**     | Типизация                                     |
| **Vite 8**             | Сборщик и dev-сервер                          |
| **TanStack Router**    | Роутинг с автогенерацией routes               |
| **TanStack Query**     | Кэширование и управление серверным состоянием |
| **MUI 9**              | UI-компоненты (Material UI)                   |
| **Lightweight Charts** | Графики цен                                   |
| **openapi-fetch**      | HTTP-клиент, сгенерированный из OpenAPI       |

## 📁 Структура проекта

```
src/
├── app/
│   ├── layouts/        # Макеты страниц (layouts)
│   └── routes/         # Определение роутов (TanStack Router)
├── features/
│   └── user/           # Функциональность, связанная с пользователем
├── pages/              # Страницы приложения
│   ├── Arbitrage/      # Страница арбитража
│   ├── DemoPage/       # Демо-версия
│   ├── History/        # История сделок
│   ├── MainPage/       # Главная страница
│   ├── NotFound/       # 404
│   ├── Profile/        # Профиль пользователя
│   ├── signin/         # Вход
│   └── signup/         # Регистрация
├── shared/
│   ├── api/            # API-клиенты и типы (из OpenAPI)
│   ├── theme/          # Тема MUI
│   ├── ui/             # Переиспользуемые UI-компоненты
│   ├── config.ts       # Конфигурация (пути, меню)
│   └── global.css      # Глобальные стили
├── widgets/
│   ├── ArbitrageTable/       # Виджет таблицы арбитража
│   └── ArbitrageTableDemo/   # Демо-виджет таблицы
└── main.tsx              # Точка входа
```

## 🚀 Быстрый старт

### Требования

- **Node.js** ≥ 18 (рекомендуется LTS)
- **npm** ≥ 9

### Установка

```bash
# 1. Перейдите в директорию проекта
cd frontend

# 2. Установите зависимости
npm install
```

### Запуск dev-сервера

```bash
npm run dev
```

Сервер запустится на `http://localhost:5173` (или другом свободном порту).

### Проверка сборки

```bash
npm run build
```

### Предпросмотр production-сборки

```bash
npm run preview
```

### Линтинг

```bash
npm run lint
```

## 🔌 API и генерация типов

Проект использует **OpenAPI** для генерации TypeScript-типов и HTTP-клиента.

### Генерация API-клиента

```bash
npm run api
```

Эта команда скачивает схему OpenAPI с бэкенда (`http://127.0.0.1:8000/api/schema/`) и генерирует типизированный клиент в
`src/shared/api/schema.ts`.

> **Важно:** Бэкенд должен быть запущен для генерации API-клиента.

## 🏗 Сборка и деплой

### Production-сборка

```bash
npm run build
```

Результат сборки будет в директории `dist/`.

### Docker

Проект включает `Dockerfile` для сборки через Docker:

```bash
# Сборка образа
docker build -t arb-frontend .

# Запуск контейнера (копирует сборку в result_build/)
docker run --rm -v $(pwd)/result_build:/app/result_build arb-frontend
```

Dockerfile основан на `node:24-alpine` и выполняет:

1. Копирование `package.json` и установку зависимостей
2. Копирование исходного кода
3. Сборку проекта (`npm run build`)
4. Копирование `dist/` в `result_build/`

## 🔤 Алиасы импортов

Для удобной навигации по проекту настроены алиасы:

| Алиас       | Путь            |
|-------------|-----------------|
| `@pages`    | `src/pages/`    |
| `@shared`   | `src/shared/`   |
| `@widgets`  | `src/widgets/`  |
| `@features` | `src/features/` |
| `@app`      | `src/app/`      |

**Пример использования:**

```tsx
// ❌ Не рекомендуется
import {SomeComponent} from '../../../shared/ui/some-component'

// ✅ Рекомендовано
import {SomeComponent} from '@shared/ui/some-component'
```
